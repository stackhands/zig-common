* zig-common

The pieces the stackhands Zig tools share: Linux system calls with named errors, file handling checked on the open descriptor, running a child program, gzip in place and the =.licensed-logs= list, and command-line plumbing.
It holds only what at least two tools need, or what one tool needs in a form the next port will reuse.
It is Linux only and needs Zig 0.17.1.

New here?
[[file:tutorials/first-tool.org][Write a small tool on zig-common]] ends with =kernel=, a program that runs =uname= with a deadline and an empty environment and prints the kernel release.
